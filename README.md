# RBAC System

Консольная утилита для управления пользователями, ролями и правами доступа с использованием модели RBAC (Role-Based Access Control).

## Ветки проекта

- main - основная ветка с финальной версией
- dev - ветка разработки
- feature/bds - базовые структуры данных
- feature/filters - фильтрация и сортировка
- feature/managers - менеджеры данных
- feature/commands - система команд
- feature/util - утилиты и форматирование
- feature/threadsafe-managers - потокобезопасные менеджеры
- feature/parallel-logs - параллельные отчёты
- feature/workers - фоновые задачи
- feature/schedule-tasks - периодические задачи
- feature/load-test - нагрузочное тестирование
- feature/async-audit - асинхронное логирование
- mnptdz - Отдельная ветка с д/з по многопоточности!
